# Приложение для составления финансовых отчетов

Приложение на Python для отслеживания и анализа финансовых операций, включая возврат денежных средств, категории расходов и мониторинг валют / запасов.

## Функции

- Отслеживание финансовых операций
- Анализ возврата денежных средств
- Отчеты о расходах по категориям
- Мониторинг курсов валют
- Отслеживание цен на акции
- Анализ истории транзакций

## Настройка

1. Клонируем репозиторий
2. Устанавливаем зависимости:
``bash
pip install poetry
poetry install
```

3. Создайте файл `.env` с необходимыми ключами API:
``env
API_KEY=ваш_обменный_api_key
API_STOCKS=ваш_сток_api_key
```
